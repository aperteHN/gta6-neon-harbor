Neon Harbor — Solstice City Heist is an original open-world crime game for the desktop browser. Explore the sun-soaked city of Solstice City on foot and by car across five districts, steal and drive cars in live traffic, run from a five-star wanted system with police on foot and in cars, fight with mouse-aimed shooting, and play Mara Vale's five-chapter heist story from Harbor Customs to the Coral Beach getaway. It has a HUD with a live minimap, synthesised sound and music, a start screen, pause, busted and ending screens, and progress that saves in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD move, E enter or exit a car, mouse aim, click to shoot, Shift sprint, K save, P pause. No build step and no network: every file the game loads lives under game/.
